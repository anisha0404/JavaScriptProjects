# 🎮 Tic-Tac-Toe Game

This project is a simple Tic-Tac-Toe game built using JavaScript, HTML, and CSS. It allows two players to take turns marking spaces in a 3×3 grid until one player wins or the game ends in a draw. ❌⭕

## ✨ Features


- Two-player gameplay. 👥
- Simple and intuitive UI. 🎨
- Displays winner or draw message at the end. 🏆
- Reset button to restart the game. 🔄

## 🛠️ How to Play

1. Open the `index.html` file in a web browser. 🌐
2. Players take turns clicking on an empty square to place their mark (X or O). ❌⭕
3. The game checks for a winner or a draw after every move. ✅
4. Click the "Reset" button to start a new game. 🔄
