💡 Light On/Off Webpage

This project is a simple JavaScript-based webpage that allows users to toggle a light bulb on and off by clicking a button. 🔘💡

✨ Features

Displays a light bulb image that switches between on and off states. 💡

Includes a button to toggle the light bulb. 🔘

Uses basic HTML, CSS, and JavaScript. 🖥️

🛠️ How to Use

Open the index.html file in a web browser. 🌐

Click the "Toggle Light" button to switch the light bulb on or off. 🔄
