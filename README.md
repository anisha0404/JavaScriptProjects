🎮 JavaScript Fun Projects

Welcome to JavaScript Fun Projects! This repository is a collection of small but exciting JavaScript projects that showcase interactivity, logic, and fun. Whether you're a beginner or a coding enthusiast, these projects will help you understand core JavaScript concepts while having fun.

🚀 Projects in this Repository

1. ✊✋✌ Rock Paper Scissors – Battle against the computer in this classic game of luck and strategy!


2. ❌⭕ Tic-Tac-Toe – Challenge a friend or the AI in this legendary 3x3 board game.


3. ➕➖ Simple Calculator – Perform basic arithmetic operations with this sleek and minimalistic calculator.


4. 💡 Bulb On/Off – Click the switch to turn the bulb on and off—experience interactive UI magic!


🛠 Tech Stack

HTML – For structuring the pages

CSS – For styling and making things look awesome

JavaScript – For adding interactivity and logic


📂 Project Details

🎮 Rock Paper Scissors

How to Play:

Choose between Rock, Paper, or Scissors.

The computer makes a random choice.

The winner is decided based on the classic rules:

Rock beats Scissors

Scissors beats Paper

Paper beats Rock


❌⭕ Tic-Tac-Toe

Features:

Play against a friend or an AI.

Highlights winning combinations.

Simple, sleek UI with animations.


➕➖ Simple Calculator

Features:

Supports Addition, Subtraction, Multiplication, and Division.

Easy-to-use number buttons.

Lightweight and functional UI.


💡 Bulb On/Off

How it Works:

Click the button to turn the bulb ON or OFF.

Simple DOM manipulation using JavaScript.

Perfect for understanding event handling.
